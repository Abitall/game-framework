# Skill Test Spec: /obsidian

## Skill Summary

`/obsidian` writes notes into the user's Obsidian vault: ideas, concepts, plans,
documents, open questions. Notes are Russian, one thought per note, linked with
wikilinks to at least two existing notes. Map cards are regenerated by the tool.

## Static Assertions (Structural)

- [ ] Resolves the vault through `production/obsidian.json`, `OBSIDIAN_VAULT` or `--vault`
- [ ] Requires a search before creating, to avoid duplicates
- [ ] Requires at least two links per note
- [ ] States that titles must avoid `: / \ ? * " < > |`
- [ ] Forbids editing notes the agent did not create without asking
- [ ] Forbids project specs and secrets in the vault
- [ ] Documents the generated map cards and that they are not edited by hand

## Test Cases

### Case 1: Happy path
**Input:** "запиши идею про каскадные комбо".
**Expected:** search runs, no duplicate found, note created in `10 Идеи`, two links added, `index` run, report with title and links.

### Case 2: Duplicate exists
**Input:** a note with the same title exists.
**Expected:** refuses to create, offers to link to the existing note instead.

### Case 3: Title with a colon
**Input:** `идея "Комбо: каскад"`.
**Expected:** the colon is stripped or the title is rephrased; no file with `:` is created.

### Case 4: Vault missing
**Input:** configured path does not exist.
**Expected:** asks before creating it, then runs `init`.

### Case 5: User asks to edit their own note
**Expected:** asks for permission first, does not rewrite the note silently.

## Verdict Criteria

- **PASS**: all assertions hold and every case matches.
- **NEEDS WORK**: one deviation.
- **FAIL**: creates a duplicate note, writes in English, or leaves a note without links.
