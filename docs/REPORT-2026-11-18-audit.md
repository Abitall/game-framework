# Отчёт: аудит после переноса документации движков

> 2026-11-18, второй проход. Первый — в `REPORT-2026-11-18.md`.

## Что сделано

### 1. Документация движков перенесена в модули

| | Было | Стало |
|---|---:|---:|
| `docs/engine-reference` | 82 файла | **22** (phaser 5 + unity 16 + README) |
| Пул `.framework/library/docs` | — | 60 файлов в пяти модулях |
| Файлов в `docs/` | 192 | **113** |

`node .framework/install.mjs add engine-godot` приносит 12 файлов документации
вместе с агентами; `remove` убирает их. Проверено на живом цикле.

Установщик получил новый тип содержимого — `docs`. Пути в манифестах
относительны `docs/`, поэтому файлы ложатся рядом с проектом, а не в `.opencode`.

### 2. Убраны Godot-инструкции из универсальных агентов

Найдено: `ai-programmer`, `engine-programmer`, `gameplay-programmer`,
`ui-programmer` велели читать `docs/engine-reference/godot/...` независимо от
стека. В Phaser-проекте это прямая дезинформация.

Заменено на `docs/engine-reference/<engine>/...` с пояснением: если каталога нет,
модуль движка не установлен.

### 3. Новый инструмент проверки

`.framework/tools/self-check.mjs` (`npm run check:self`):

- каждый файл библиотеки принадлежит ровно одному модулю;
- ни один модуль не ставится с ошибкой и не оставляет мусора после удаления;
- `installed.json` не меняется после полного цикла add/remove всех 22 модулей;
- нет двух байт-идентичных файлов под разными именами;
- нет битых markdown-ссылок;
- агент не ссылается на документацию чужого движка.
