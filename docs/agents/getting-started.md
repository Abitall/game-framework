# Getting Started

```bash
/start                      # guided onboarding, routes to the right phase
/concept-brainstorm         # explore game ideas from scratch
/setup-engine phaser 4.2.1  # pin the engine (also: unity, godot, unreal, sfml3, raylib, bevy)
/project-stage-detect       # analyse an existing project
/prototype                  # rapid prototype
```

`/setup-engine` and `/start` propose the engine and domain modules the project
needs.
