# Context Management

Context is the most critical resource. Manage it actively.

**The file is the memory, not the conversation.** Conversations are ephemeral
and will be compacted or lost; files persist.

Maintain `production/session-state/active.md` as a living checkpoint. Update it
after each significant milestone:

- design section approved and written
- architecture decision made
- implementation milestone reached
- test results obtained

It should contain: current task, progress checklist, key decisions, files in
play, open questions.
